SQL

I am using SQL to manipulate and analyze data.

Layoffs

In this practice project, I follow @AlexTheAnalyst's tutorial to perform a data cleaning on and analyze layoffs data using SQL.

In the data cleaning process, I remove duplicates, correct inconsistencies to ensure data quality, identify and handle missing values, and remove unnecessary columns.

Through the analysis, I perform various queries, such as aggregation, window functions, and other SQL techniques, to extract meaningful insights.

Black Friday Sales

I first apply a data validation process to ensure no missing or inconsistent data is present in the dataset. Since the data is clean, I can proceed with the analysis to identify sales trends and customer behavior patterns.

I do a global analysis of the sales data to uncover key insights. Then I analyze the data in more detail to identify specific trends and opportunities, such as city-purchase patterns or gender-based purchasing behaviors.
